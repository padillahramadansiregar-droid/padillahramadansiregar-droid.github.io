Proyek utama: Portofolio Personal

Web App · 2026Sedang Dikembangkan

Portofolio Personal

Website portofolio multi-halaman untuk menampilkan profil, pendidikan, keahlian, proyek, dan kontak. Dibangun dengan Next.js dan Tailwind CSS dengan bantuan AI, lalu disesuaikan sendiri. Seluruh konten ditulis apa adanya, tanpa metrik fiktif atau klaim yang belum bisa dibuktikan.

  • Lima halaman utama: Beranda, Tentang Saya, Keahlian, Proyek, dan Kontak
  • Formulir kirim email dengan validasi nama, email, subjek, dan pesan
  • Tema gelap bergaya editorial teknis, dengan tampilan responsif untuk HP dan desktop
  • Kontak langsung lewat email, WhatsApp, GitHub, dan LinkedIn
  • Next.js
  • React
  • TypeScript
  • Tailwind CSS

Situs yang sedang Anda buka ini adalah proyeknya. Kode sumbernya terbuka dan bisa dilihat langsung di GitHub.

Cara Situs Ini Dibangun

  • Struktur halaman

    Lima halaman utama (Beranda, Tentang Saya, Keahlian, Proyek, Kontak) ditambah satu rute formulir kirim email.

  • Teknologi

    Next.js dengan App Router, React, TypeScript, dan Tailwind CSS.

  • Konten terpusat

    Teks profil, pendidikan, dan keahlian disimpan di satu berkas data, sehingga mudah diperbarui tanpa mengubah tampilan.

  • Publikasi

    Kode tersimpan di repository GitHub publik dan dipublikasikan ke GitHub Pages melalui GitHub Actions.
