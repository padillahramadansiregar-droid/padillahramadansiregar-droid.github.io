PETUNJUK FOTO PROFIL — PADILLAH RAMADAN SIREGAR
==============================================
Untuk menampilkan foto profil asli Anda:
1. Simpan file foto Anda dengan nama `profile.jpg` di dalam folder ini (`public/images/profile.jpg`).
2. Aplikasi Next.js akan langsung mendeteksi dan menampilkan foto tersebut di halaman Beranda (Hero) dan Tentang Saya.
3. Jika file foto belum diletakkan di sini, aplikasi secara otomatis menampilkan monogram resmi `PRS` (Padillah Ramadan Siregar) dengan gaya Midnight Technical Editorial.
